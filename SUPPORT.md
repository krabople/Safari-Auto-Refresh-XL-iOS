# Auto Refresh XL Support

Auto Refresh XL is a Safari extension for automatic page refreshing and local webpage monitoring on iPhone and iPad.

## Setup

1. Open **Settings → Apps → Safari → Extensions**.
2. Select **Safari Auto Refresh and Page Monitor XL** and enable it.
3. Allow access to the websites on which you want to use the extension.
4. In Safari, open a webpage, tap the Page Menu button, and select **Auto Refresh XL**.

## Troubleshooting

- Keep Safari open and visible while an active refresh session is running.
- Confirm that the extension has permission to access the current website.
- For audible alerts, check the device volume and Ring/Silent setting.
- Some Safari internal pages, document viewers, closed components, images, and canvas-rendered text cannot be monitored.
